El diseño de Arquitectura de SOftware

El diseño de arquitectura de software es el proceso de planificar y organizar la estructura de un sistema informático antes de programarlo.

El diseño de arquitectura de software es el proceso de planificar y organizar la estructura de un sistema informático antes de programarlo.

Se le llama “arquitectura” porque funciona como el plano de una casa: antes de construir, se decide dónde estarán las habitaciones, puertas y conexiones. En software, se decide cómo se dividirá el programa en módulos, servidores, bases de datos, interfaces y servicios.
